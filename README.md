## 🎮 Games I've Developed

All built during game jams (some 2 days, some a week) in **Godot (GDScript)**. Most are playable in the browser on [itch.io](https://diegobangles.itch.io).

### 🏰 [LEAVE MY DUNGEON!](https://github.com/hugomarques13/Dungeon-Game) &nbsp;·&nbsp; [▶️ Play](https://diegobangles.itch.io/leave-my-dungeon)
A reverse dungeon crawler where the player acts as the dungeon overseer, placing units, traps and field effects to fight off human intruders. Features 12+ units and 15+ intruders in turn-based combat. *(Mar 2026)*

### 🌍 [As the Lord Intended](https://github.com/hugomarques13/As-the-Lord-Intended) &nbsp;·&nbsp; [▶️ Play](https://diegobangles.itch.io/as-the-lord-intended)
A 2D platformer in which the player manipulates the world itself to solve puzzles. *(Feb 2026)*

### 🎯 [Crosshue](https://github.com/hugomarques13/bullet-hell-game) &nbsp;·&nbsp; [▶️ Play](https://diegobangles.itch.io/crosshue)
A progressive bullet-hell where the boss grows stronger the more it is damaged. Switch hues to avoid damage and consume corpses for sustenance. All animations are generated procedurally. *(Feb 2026)*

### 🥚 [Fowl Discount](https://github.com/hugomarques13/Fowl-Discount) &nbsp;·&nbsp; [▶️ Play](https://diegobangles.itch.io/fowl-discount)
A side-scrolling stealth platformer built for **Mini Jam #47** (60-hour jam, theme "Cheap Copy", special object "Egg"). The player controls Gally, a chicken reclaiming her stolen eggs without being caught. *(Sep 2025)*

### 🍪 [Cookie's Gambit](https://github.com/FelipeSiqueira13/cookie-monster-game) &nbsp;·&nbsp; [▶️ Play](https://diegobangles.itch.io/cookies-gambit)
A roguelike top-down game built for **Brackeys Game Jam 2025.2** (7-day jam, theme "Risk it for the biscuit"), featuring procedural room generation for a unique layout every run. *(Aug 2025)* *(team project)*
